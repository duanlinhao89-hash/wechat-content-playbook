# 02 · 六幕叙事法

> 最高优先级铁律。目标：像看电影一样，一步一步推进，读完豁然开朗。

---

## 一、先回答一个问题，再动笔

**"这件事的因果链是什么？"**

答不出来，就不要写。文章必须是**一个完整事件**，不是几条信息的拼盘。
六幕叙事法的设计初衷，就是强制作者先找到因果链，再把它铺陈成一条读者能跟着走的线。

它来自成熟的新闻特稿与故事写作方法：

- 《华尔街日报》特稿结构：**导语（Show, not tell）→ Nut graph（核心段落，早点点题）→ 背景 → 若干因果相连的 Block → 解答所有疑问的结尾**；
- 叙事弧线：**阐述 → 上升动作（篇幅最大，每步留悬念）→ 危机 → 高潮 → 结局（解开一切结，要短）**；
- 财经故事化：**场景之间必须有因果关系，小标题分割章节但每节开端要释放一个亮点**。

---

## 二、六幕结构（顺序不许打乱）

| 幕 | 作用 | 硬性要求 |
|---|---|---|
| ① 开场 | 一个具体画面 | 一个有时间、有数字、有人的场景，**不用概念开头**。例："11 月 4 日，道指涨了 1500 多点……" |
| ② 点题（Nut graph） | 告诉读者为什么值得读 | **开头 200 字内必须出现**。1–2 段，直接点破"这件事真正在改变的是什么"。这是治"思维混乱"的关键——读者要早早拿到地图 |
| ③ 起因 | 事情为什么会开始 | 交代背景和触发点，只给支撑故事必需的信息，**不许把背景一股脑倒在前头** |
| ④ 推进 | 篇幅最大，占全文 40% 以上 | 分 3–4 步，每一步都建立在上一步之上。每一步必须回答"然后呢 / 所以呢"，用因果连接句推进，不能跳步 |
| ⑤ 高潮 | 最反常识、最紧张的一刻 | 一个反转或一次集中爆发，把④攒的张力收束到一个具体事实/数字上 |
| ⑥ 结局与影响 | 解开所有的结 | 各方怎么回应、事情外溢到哪、留下什么没解决。读者到这里所有疑问都要有答案 |

### 一个真实例子的骨架拆解

以范文《单季首破千亿，毛利率却掉了 3 个点》为例：

- **① 开场**：11 月 17 日下午四点纽约收盘，英伟达 155.46 美元；四小时后财报出炉，股价盘后拉回 163。
- **② 点题**："这份财报真正的新闻，不是营收第一次破千亿，而是一个卖芯片的人开始替客户垫钱。"
- **③ 起因**：买单的名单变了——新客户需求真、资产负债表薄。
- **④ 推进**（占最大篇幅）：卡住的不是芯片而是内存 → 越老的卡越贵 → 一张比营收还大的担保。
- **⑤ 高潮**："卖芯片的人，最后替客户担保了土地、电和厂房。"
- **⑥ 结局**：市场给出两组相反读数，账单如何传导到普通人，三个观察点，整条链重讲一遍，结论句收束。

完整范文见 [`examples/成稿示例-英伟达财报.md`](../examples/成稿示例-英伟达财报.md)。

## 三、结尾：必须有真正的收束（治"戛然而止"）

顺序固定，**不许省略任何一段**（按阅读顺序排列）：

1. **影响段**：这件事改变了什么、谁付账、谁得利。
2. **三个观察点**（可选，最多 3 条、每条 1 句）：只能写成"接下来盯什么"，**绝对不能当文章结尾**。推荐放在影响段之后、总结之前；无论放哪里，**其后必须还有总结性概括、首尾呼应与结论句**。
3. **总结性概括**：3–5 句，把整条因果链重讲一遍。读者读完应该"哦，原来是这样"。
4. **首尾呼应**：回扣开场那个画面或那句话，形成闭环。
5. **结论句**（正文最后一段，必须有）：以「因此 / 所以 / 说到底 / 到头来」开头，**一句**把全篇最终判断明说出来。
6. **一行小字免责**：不算正文，结论句之后只留这一行。

### 结论句怎么写（最容易出错的一环）

- 必须是**判断**，不是金句、不是感慨、不是反问、不是"接下来盯什么"。
- 只写一句，不展开成一段。
- 必须能被单独摘出来复述，且不引入前文没出现过的新事实。
- 不预测涨跌、不给买卖建议、不写成口号。
- **自检**：把这句单独发给别人，对方不读全文也能明白这篇文章到底想说什么；做不到就是没写到位。
- 与"一句话总结"的区别：凝练金句读者读完仍不知道结论是什么。金句可以留在首尾呼应段里，**但不能占结论句的位置**。

## 四、连续性的硬检查

这是区分"好文章"和"信息拼盘"的关键。

- 每个小节的**第一句必须是承接句**，明确和上节的关系（"问题出在……""但第二天……""真正让局面反转的是……"）。禁止每节另起炉灶。
- 相邻段落之间不许出现逻辑跳跃：**上一段的结论，是下一段的起点**。
- **禁止把句子强行拆成孤立的短段落**。设问被拆出来加粗放大，是"断断续续"的元凶。
- 时间线必须清楚：日期、先后顺序、"前一天/当天/第二天"要能一眼对上。
- **写完自检**：遮住小标题，通读一遍，看能不能顺下来讲给别人听。讲不顺就是结构有问题，回去改，不要靠加小标题掩盖。

---

## 五、篇幅

建议 **2400–3200 中文字**。

- 低于 2400 字，六幕叙事讲不完因果链；
- 高于 3200 字，手机读不完。

以这条为准；若其他文档或 prompt 里出现旧的数值（如 2200–2800），不再适用。

---

## 六、自检清单（发布前逐项打勾）

- [ ] 开头 200 字内出现了点题段（Nut graph）
- [ ] 第④幕篇幅占全文 40% 以上
- [ ] 每个小节第一句是承接句
- [ ] 相邻段落之间存在明确因果，无跳步
- [ ] 高潮落在一个具体的事实或数字上
- [ ] 有真正的结论句，以"因此/所以/说到底"开头，独立成一句
- [ ] 结尾有首尾呼应，回扣开场画面
- [ ] 遮住小标题通读，能顺利讲给别人听
- [ ] 字数在 2400–3200 之间

---

## 小结

六幕叙事法的本质是：**先找到因果链，再用六幕把它铺成一条读者能走的路，最后用结论句收口。**
