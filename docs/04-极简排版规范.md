# 04 · 极简排版规范

> 诊断：排版混乱的根源，是一篇文章里同时出现太多颜色、太多色块、太多"重点"。
> 本规范的核心：**限制颜色数、限制色块数、限制加粗数**，把排版参数固定下来。

---

## 一、三条总原则

1. **文字颜色固定 3 种**：深褐 `#1F1B16`（标题/正文）、暗金 `#A8752A`（唯一强调色）、灰 `#9A9187`（辅助信息/图注/免责）。另允许 3 个固定中性值作底色与描边：米白 `#FBF6EC`、米金边 `#E8DCC6`、浅线 `#EFE5D2`。**除此 6 个色值外不许出现第 7 个**。
2. **全篇最多 2 个色块**，且必须是下面这两种；其他一律不许出现。
3. **划重点要克制**：1 屏之内最多 1 处加粗，全篇加粗不超过 6 处。

> 注意：上面的 6 个色值是 **HTML 文字与底色的限制**，不是配图配色指令。曾把它们直接写进图片 prompt，又叠了"深色场景"，才导致配图偏暗偏黄。这条要反复记住。

---

## 二、唯一允许的两种色块

| 模块 | 位置 | 写法 |
|---|---|---|
| **导读卡** | 点题段之后，全篇仅 1 次 | 米白底 `#FBF6EC` + 1px `#E8DCC6` 边 + 3px 暗金顶条；**最多 3 行**，写"这一篇讲什么 / 会怎么讲"。不写"今天的三个问题" |
| **结论句** | 正文最后一段，全篇仅 1 次 | **不用底色块**：上方 1px `#E8DCC6` 细线 + 一句 17px 加粗深褐，以「因此 / 所以 / 说到底」开头，写全篇最终判断 |

### 导读卡写法

```html
<section style="margin:0 0 8px;padding:16px 18px 15px;background:#FBF6EC;border:1px solid #E8DCC6;border-top:3px solid #A8752A;">
  <p style="margin:0;font-size:14.5px;line-height:1.85;color:#1F1B16;">一份创纪录的财报里，唯一往下走的是毛利率。这一篇讲这 3 个点被谁拿走，以及一家毛利 75% 的公司为什么愿意让出去。</p>
</section>
```

### 结论句写法

```html
<p style="margin:24px 0 0;padding-top:16px;border-top:1px solid #E8DCC6;font-size:17px;font-weight:bold;color:#1F1B16;line-height:1.7;">因此，这一轮扩张最先被让出去的不是订单，而是毛利率。</p>
```

### 永久停用清单

导语卡里的三问、数据卡、人话框、金句块、观察点卡、链条卡、免责卡、任何实底彩色块。
（结论句不是被停用的"金句块"：它有明确的因果落点和结论引导词，且位置固定在正文末尾。）

## 三、统一参数表

| 元素 | 参数 |
|---|---|
| 正文 | 16px / 行距 1.75 / 段间距 18px / 颜色 `#1F1B16` |
| 眉标 | 11.5px 暗金 `#A8752A` / 字距 4px |
| H1 标题 | 25px 粗体深褐 / 行距 1.42 / 超 14 字手动断行 |
| 副信息 | 12.5px 灰 `#9A9187` / 日期 · 字数 |
| 标题下短横线 | 52×3px 暗金 |
| 小标题 | `01`–`06` 序号 + 左侧 4px 暗金竖条 + 19px 粗体深褐；与上留 32px、与下留 12px |
| 图注 | 12.5px 灰 / 居中 / 讲这张图在说什么 |
| 免责行 | 11.5px 灰 / 顶部 1px `#EFE5D2` 细线 |

### 标题区完整骨架（正文最上方四行）

```html
<p style="margin:0 0 14px;font-size:11.5px;color:#A8752A;letter-spacing:4px;line-height:1.6;">老段 · 财经拆解</p>
<h1 style="margin:0 0 14px;font-size:25px;font-weight:bold;color:#1F1B16;line-height:1.42;letter-spacing:0.5px;">标题第一行，<br />标题第二行</h1>
<p style="margin:0 0 16px;font-size:12.5px;color:#9A9187;line-height:1.7;">2026 年 11 月 18 日&nbsp;&nbsp;·&nbsp;&nbsp;全文约 3200 字</p>
<div style="width:52px;height:3px;background:#A8752A;margin:0 0 30px;"></div>
```

### 小标题骨架

```html
<h2 style="margin:32px 0 12px;padding-left:12px;border-left:4px solid #A8752A;font-size:19px;font-weight:bold;color:#1F1B16;line-height:1.5;">01　数字都对，只有一格往下走</h2>
```

小标题用**陈述短句**，不用问句堆叠。

---

## 四、正文段落与设问

- 正文段落：`margin:0 0 18px;font-size:16px;line-height:1.75;color:#1F1B16;`
- 段落末尾（每小节最后一段）：`margin:0 0 22px;...`
- **设问**：融入段落，不单独成段、不放大、不加粗。全篇最多 1 处关键设问可以用 16px 加粗。
- 中英文 / 数字之间加半角空格；标点统一全角。

---

## 五、配图排版（HTML 部分）

配图的**内容与色调**见 [`05-标题封面与配图.md`](05-标题封面与配图.md)，这里只讲 HTML 呈现。

- **通栏满宽、左右零留白**：`figure` 用 `margin:0 -16px 6px -16px` 抵消编辑器内边距；`img` 用 `width:100%;display:block;border-radius:0;`，无圆角。

```html
<figure style="margin:0 -16px 6px -16px;">
  <img src="images/01_内存.png" style="width:100%;display:block;border-radius:0;" alt="描述图内容" />
</figure>
<p style="margin:0 0 22px;font-size:12.5px;color:#9A9187;text-align:center;line-height:1.6;">图注：讲这张图在说什么，不写来源。</p>
```

- 图注留在文字栏内，**不写"图片来源"，不写"AI 生成"**。
- 正文图裁成 16:9（1080×608）或 3:2（1080×720），禁止接近正方形。
- 图片用相对路径，**禁止 base64 内嵌**。
- 图跟着叙事走：开场 / 推进 / 高潮 / 影响各放一张，不要三张堆一起。

---

## 六、技术约束

- 全部内联样式，禁用外链 CSS 与 `<style>` 标签（公众号编辑器会清洗）。
- 禁止 `#000000`、`#16181D` 等近黑实底。
- 交付 `article.html`（可直接粘进编辑器）+ `预览.html`（414px 宽、左右内边距 16px 的容器）。

可直接使用 [`templates/排版骨架.html`](../templates/排版骨架.html) 作为起点。

---

## 七、排版自检清单

- [ ] 全文只出现 6 个规定色值，无第 7 个
- [ ] 全篇只有 2 个色块：导读卡 + 结论句
- [ ] 全篇加粗不超过 6 处，一屏内最多 1 处
- [ ] 没有停用的色块（数据卡/金句块/观察点卡等）
- [ ] 标题区四行齐全，参数正确
- [ ] 小标题用陈述短句，带序号和竖条
- [ ] 图注居中、灰色、不写来源
- [ ] 全部内联样式，无 `<style>` 标签
- [ ] 图片用相对路径，无 base64

---

## 小结

极简排版的本质是**用限制换取清晰**：颜色少、色块少、重点少，叙事线才不会被切碎。
把参数固定下来，排版就不再是每次重新发挥的玄学，而是可直接套用的骨架。
