# 05 · 标题、封面与配图

> 标题决定点开率，封面和配图决定第一印象。三者都遵守同一条原则：**清楚、克制、说明事实。**

---

## 一、标题公式

**一个反常识的转折 + 一个具体数字或时间。**

规则：

- ≤ 22 字，优先 12–18 字；
- 少用感叹号；
- 冷启动期少用生僻人名，用身份词替代（"美联储主席"优于人名）；
- 标题必须能在封面上排成两行，首行可用逗号断句；
- **标题定了，封面必须跟着出；标题改了，封面必须重做。**

### 好标题拆解

| 标题 | 转折 | 数字 / 时间 |
|---|---|---|
| 单季首破千亿，毛利率却掉了 3 个点 | "却"——破纪录与掉毛利 | 千亿 / 3 个点 |
| 崩了 30% 的黄金，今天自己爬回去了 | "崩了 vs 爬回去" | 30% / 今天 |
| 33 万人爆仓，输给一条平均线 | "人 vs 一条线" | 33 万 |
| 涨了一天，蒸发 2.9 万亿美元 | "涨 vs 蒸发" | 一天 / 2.9 万亿 |
| 估值砍了一半，8954 亿美元的账单没砍 | "砍 vs 没砍" | 一半 / 8954 亿 |

共同点：**两个相反方向的事实被压进一句话**，读者一看就有认知冲突，想知道为什么。

## 二、封面规范

- 封面尺寸：出图直接 `size="1536x654"`（2.35:1），一次把文字写进 prompt；
- 封面**自带标题**（白色两行，左上）+ 左下角金色署名「老段有话讲」；
- 交付 `00_封面.png`（900×383）；
- HTML 用相对路径 `images/00_封面.png`，禁止 base64 内嵌。

### 白字标题的局部遮罩

白字需要对比度，但**不许把整图压暗**。做法是只在文字区加一层半透明深色遮罩，其余保持清透。
用随附的 [`tools/scrim.py`](../tools/scrim.py)（局部羽化压暗，不整图压暗）：

```bash
python scrim.py 源.png 输出.png x0 y0 x1 y1 强度 羽化 [保护阈值]
# 例：左上文字区压暗到 0.5，羽化 120px，保护 >=200 的高光像素
python scrim.py cover.png cover_masked.png 0 0 900 320 0.5 120 200
```

参数说明：`x0 y0 x1 y1` 是压暗矩形（可超出画布让边缘落在画外），强度 0–1，羽化为渐变像素宽度，可选"保护阈值"避免压掉白色标题本身。

## 三、配图原则（最容易被做错的一环）

### 核心原则

**图的作用是说明事实，不是渲染情绪。**

- 客观、清楚、明亮、自然光；
- 白天自然光或明亮室内，主体一眼能认出是什么（交易大厅 / 机房 / 线缆 / 屏幕）；
- 避免低照度、暗角、重阴影、烟雾感、强滤镜、冷蓝末日感；
- 宁可平实，不要"有氛围但看不清"。

### 常见的坑：把文字配色写进图片 prompt

第八节那 6 个色值（深褐/暗金/灰等）是 **HTML 的限制**，不是画面配色指令。
曾把它们直接写进图片 prompt，又叠了"深色场景"，导致每篇图都偏暗偏黄、看着不客观。
**记住：配图不要追求和文字配色统一。**

### 出图 prompt 用词

- ❌ 禁用：`dimly lit` / `moody` / `dark` / `low-key` / `noir` / `dramatic shadows` / `cinematic gloom` / `amber haze`
- ✅ 改用：`bright natural daylight` / `evenly lit` / `neutral color` / `clean` / `documentary` / `clear detail` / `light background`

### 自检

把图缩到手机宽度看，主体还认得出就合格；认不出就是太暗或太花，重做。

---

## 四、配图规格

- 正文图 1 张封面 + 3 张正文图；
- 正文图裁成 16:9（1080×608）或 3:2（1080×720），禁止接近正方形；
- **所有图必须裁掉右下角 AI 水印**，一张都不许留。用 [`tools/png_crop.py`](../tools/png_crop.py)：

```bash
# 正文图：裁 (0,0)-(1536,929) 并缩放到宽 1080
python png_crop.py raw.png 01_内存.png 0 0 1536 929 --resize 1080
# 封面：裁 (63,0)-(1410,600) 并缩放到宽 900
python png_crop.py raw_cover.png 00_封面.png 63 0 1410 600 --resize 900
```

具体裁剪框要按每张原图的实际水印位置调整，上面只是常用值。

---

## 五、已知限制（少走弯路）

- 图像模型通常**不生成真人政治人物、不生成国旗**。需要人物时让用户提供照片，用编辑模式只压标题与署名，不要反复试错白烧积分。
- 图注**不写"图片来源"，不写"AI 生成"**——公众号语境下这两行会破坏叙事质感，也不符合本手册的克制原则。

---

## 六、标题 · 封面 · 配图自检清单

- [ ] 标题 ≤22 字，含转折 + 具体数字/时间
- [ ] 标题能排成封面两行
- [ ] 标题定稿后再出封面；标题改则封面重做
- [ ] 封面白字用局部遮罩，未整图压暗
- [ ] 配图为明亮自然光、主体清晰
- [ ] 图片 prompt 未使用暗色调禁用词
- [ ] 所有图已裁掉 AI 水印
- [ ] 正文图为 16:9 或 3:2
- [ ] 图注居中、灰色、不写来源
- [ ] 手机宽度下主体可辨认

---

## 小结

标题靠"认知冲突"抓人，封面和配图靠"清楚"留住人。
三者共同的敌人都是"过度"：标题过度夸张、封面过度压暗、配图过度渲染。
保持克制，让内容自己说话。
