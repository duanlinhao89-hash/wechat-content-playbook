## 三、叙事结构

- 核心要求：文章是一个完整事件还是信息拼盘？
- 动笔前必答的一句话：“这件事的因果链是什么？”
- 采用六幕结构（开场 / 点题 / 起因 / 推进 / 高潮 / 结局），篇幅分配如何？
- 结尾收束顺序：影响段 → 观察点 → 总结 → 首尾呼应 → 结论句 → 免责行
- 结论句写法要求（以「因此/所以/说到底」开头、独立一句、不引入新事实）
- 篇幅：____ – ____ 字
