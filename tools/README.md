# 图片处理工具

两个**零依赖**脚本，只用 Python 标准库（Python 3.x），拿到就能跑，无需 `pip install`。

设计初衷：把封面 / 正文图的机械处理（裁水印、缩放、白字遮罩）自动化，避免每次手动操作。

---

## png_crop.py · PNG 裁剪与缩放

纯标准库实现的 PNG 解码 / 编码，支持 8bit RGB / RGBA 非隔行 PNG。

### 用途

1. **裁掉 AI 生成图右下角的水印**（必须，一张都不许留）；
2. 按比例缩放图片到目标宽度。

### 用法

```bash
# 仅裁剪：src dst x y w h
python png_crop.py raw.png 01_内存.png 0 0 1536 929

# 裁剪并缩放：在最后加 --resize 目标宽度
python png_crop.py raw.png 01_内存.png 0 0 1536 929 --resize 1080
python png_crop.py raw_cover.png 00_封面.png 63 0 1410 600 --resize 900
```

参数：`x y` 是左上角坐标，`w h` 是裁剪框宽高，`--resize` 后接目标宽度（高度按比例自动算）。

> 常用值：正文图 `0 0 1536 929 --resize 1080`，封面 `63 0 1410 600 --resize 900`。
> 但**具体裁剪框要按每张原图的实际水印位置调整**，别照抄。

### 实现说明

- 自己实现了 PNG 的 5 种行滤波器（None/Sub/Up/Average/Paeth）解码；
- 缩放用 box 平均，避免最近邻的锯齿；
- 不依赖 Pillow，适合在没有第三方库的环境里跑。

## scrim.py · 白字标题局部羽化遮罩

给白色标题做**可控遮罩**，只压暗文字区，不把整图压暗。

### 用法

```bash
python scrim.py 源.png 目标.png x0 y0 x1 y1 强度 羽化 [保护阈值]
```

- `x0 y0 x1 y1`：压暗矩形坐标（可超出画布，让边缘落在画外）；
- `强度`：0–1，0.5 表示该区域亮度乘 0.5；
- `羽化`：渐变像素宽度，越大边缘越柔和；
- `保护阈值`（可选）：亮度 ≥ 该值的像素不压暗，用于保护白色标题本身。

示例：

```bash
python scrim.py cover.png cover_masked.png 0 0 900 320 0.5 120 200
```

### 为什么不用整图压暗

把整张图压暗会让配图显得阴暗、不客观，违背配图原则。局部羽化遮罩只在白字所在区域提供对比度，其余部分保持清透明亮。
